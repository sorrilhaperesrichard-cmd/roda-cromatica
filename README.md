# Roda Cromática

Roda cromática para tatuador: receitas de mistura em gotas (vermelho, amarelo, azul e branco, sem preto), por tamanho de batoque.

Funciona offline depois da primeira abertura. Nada sai do aparelho.

Abrir: `https://sorrilhaperesrichard-cmd.github.io/roda-cromatica/` (com a barra no final)

Mistura de pigmentos: [spectral.js](https://github.com/rvanwijnen/spectral.js) (MIT).
